# Ekin Baca Software

Angebotsseite für lokale KI-Assistenten, Automatisierung und eigene Tools für kleine Betriebe in Stuttgart.

Eine einzelne statische Seite ohne Build-Schritt: `index.html` plus Videos und Bilder in `media/`.

## Lokal ansehen

```bash
python3 -m http.server 8000
```

Dann `http://localhost:8000` im Browser öffnen.

## Inhalt

- Intro mit Zähler, rotierende Überschrift, Laufband
- Angebot mit Videovorschau am Mauszeiger
- Projekte mit mitlaufendem Video (AETHER-OS, OmniDesk Hub, RepoVerse, Sentio Systems)
- Kennzahlen, Ablauf, FAQ und ein Anfrage-Baukasten zum Kopieren
- Hell- und Dunkelmodus, `prefers-reduced-motion` wird beachtet
